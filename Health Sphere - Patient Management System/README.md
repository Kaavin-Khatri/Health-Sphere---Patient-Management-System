# Health Sphere - Patient Appointment Management System

A modern, responsive web application for managing doctor appointments.

## Features

- **Landing Page**: elegant UI for patients to book appointments.
- **Doctor Dashboard**: view and manage upcoming appointments.
- **Backend API**: RESTful API built with Node.js and SQLite.

## Prerequisites

- Node.js installed on your machine.

## Installation

1.  Clone or download the repository.
2.  Open a terminal in the project folder.
3.  Install dependencies:
    ```bash
    npm install
    ```

## Running the Project

1.  Start the server:
    ```bash
    node server.js
    ```
2.  Open your browser and navigate to:
    - **Home**: [http://localhost:3000](http://localhost:3000)
    - **Dashboard**: [http://localhost:3000/dashboard.html](http://localhost:3000/dashboard.html)

## Technologies

- **Frontend**: HTML5, Bootstrap 5, Custom CSS, JavaScript (Fetch API).
- **Backend**: Node.js, Express.js.
- **Database**: SQLite3.
